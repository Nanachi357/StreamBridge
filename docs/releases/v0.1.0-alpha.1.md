# StreamBridge v0.1.0-alpha.1 — release note draft

**Unpublished draft. Final installer acceptance is pending.** Remove this line
only after the exact release files pass the documented acceptance checks.

An experimental Windows application for finding supported media streams requested
by a browser and saving them as MP4. By Vladyslav Ponomarenko (Nanachi357).

## Install and use

Windows 11 x64 with Microsoft Edge Stable installed is required. Download
`StreamBridge-0.1.0-alpha.1-windows-x64.exe` from this release, install for your user,
then open StreamBridge from the desktop or Start Menu. Java and FFmpeg are included;
no development tools are needed. The installer is unsigned and Windows may display
a reputation warning. Do not disable Windows security protections.

Paste a page address, start the intended player in the separate Edge window,
choose a source/quality/audio and optionally preview before downloading. Downloads
is the default folder; your chosen alternative is remembered. Only save content
you own or are authorized to save.

## Alpha limits

- Finite, unencrypted HLS with MPEG-TS only; no general DASH/YouTube/DRM support.
- Compressed manifests and some HLS features are unsupported; not every source
  listed by a player can be downloaded. Passive discovery sees actual requests.
- One operation at a time; no job resume after restart or automatic updater.
- Preview budgets and per-segment limits apply; see the repository README.
- Edge updates independently; its automation can be restricted by system policy.

The application is experimental and supplied without warranty under its license;
third-party component terms remain separate. Report reproducible problems through
the repository's issue tracker. Do not attach cookies, session URLs or raw logs
containing personal information. Follow SECURITY.md for security reports.

## Files accompanying the installer

- `SHA256SUMS.txt`, `release-manifest.json` and `payload-manifest.json` identify the
  exact files. Checksums verify bytes, not the identity of a signer.
- `StreamBridge-0.1.0-alpha.1-java-materials.zip` contains Java source/build materials.
- `StreamBridge-0.1.0-alpha.1-ffmpeg-materials.zip` contains the matching FFmpeg
  runtime, source, build and development materials.
- `wix3141-source.tar.gz` supplies the matching installer-tool sources.

You do not need the source/material archives to use StreamBridge. They accompany
the binary for source availability and modification rights. Licenses/notices are
also included in the installed application. Uninstall preserves completed videos,
preferences and diagnostic files in your user profile.
