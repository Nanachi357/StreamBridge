Підключення…

1. Відкрити сторінку

Окремий ізольований Chromium. Запусти потрібне відео в його плеєрі. Час пошуку не обмежений: обери потік і натисни «Перевірити вибір» або скасуй пошук. Звичайний профіль браузера не використовується.

2. Вибрати потік

Спочатку відкрий сторінку.

Як знайти потрібне джерело

Прокрути до потрібного відео, вибери плеєр і серію, натисни Play. За потреби зміни якість. Завантаження залежить від логіки сайту; просто почекати не завжди достатньо. Реклама також може створити окреме джерело — перевір фрагмент перед повним завантаженням.

Одна вкладка пошуку: додаткові вкладки цього ізольованого вікна закриваються. Перехід на іншу сторінку чи її перезавантаження очищає попередній список. Після «Перевірити вибір» браузер закривається, а вибраний потік завантажується незалежно від сторінки. Закриття вкладки цього UI не завершує застосунок — для цього є вікно запуску.

Дані карток — із запитів браузера та плейлистів, без завантаження фрагментів. Тривалість з’явиться після отримання завершеного плейлиста відповідної якості; для прямого ефіру загальна тривалість невідома. Роздільність і звук буде перевірено під час отримання медіа.

Кожне джерело — окремий HLS-плейлист, не гарантовано окреме відео. Програма не визначає за тебе, що є основним контентом або рекламою. Поки підтримується лише обмежений набір HLS з MPEG-TS.

Після цього вікно пошуку закриється.

Куди зберегти відео

За замовчуванням — системна папка «Завантаження». Вибрана папка запам’ятовується між запусками StreamBridge. Наявні файли не перезаписуються.

3. Підтвердити завантаження

Великий або невідомий обсяг. Буде завантажено весь вибраний потік. Оцінка розміру приблизна.

Налаштування фрагмента

Довший фрагмент потребує більше трафіку, часу й місця на диску. Отримуються цілі початкові сегменти; фактична тривалість MP4 може трохи відрізнятися на межі кадрів та аудіопакетів.

Початок саме вибраного потоку, без зменшення роздільності та повторного стискання відео чи звуку. Для оцінки деталей розгорни плеєр на весь екран. Відтворення залежить від підтримки оригінальних кодеків браузером. Якщо це не те відео — скасуй операцію та почни новий пошук.

На підтвердження — 2 хвилини. Після підготовки передперегляду відлік почнеться знову. Без відповіді операцію буде скасовано.

Стан операції

Готовий до роботи

Не вдалося підтвердити очищення. У робочій папці могли залишитися часткові файли; автоматично їх не видаляємо.

Файл готовий

Зберегти MP4 через браузер

Готовий MP4 уже збережено локально за вказаним шляхом. Кнопка дозволяє зберегти додаткову копію.

Технічний звіт для передачі

Лише дозволені поля стану, прогресу й код помилки. Без адрес, назв сторінок, шляхів, cookies, токенів або медіа. Це не сирий журнал браузера.

Зберегти JSON

Одна активна операція за раз. Без відновлення після перезапуску. UI доступний лише на цьому комп’ютері; не передавай його стартове посилання іншим.
