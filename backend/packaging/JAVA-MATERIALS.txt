https://github.com/adoptium/temurin-build/tree/1cf43d7a3e77886bfea7d550a902e151a87d724d

Read the source and build-script documentation for upstream build prerequisites.

these build tools are not needed to install StreamBridge. This material set does
not claim that we rebuilt Temurin or established byte-for-byte reproducibility.

StreamBridge does not patch OpenJDK sources. packageWindowsApp in the included
streambridge-build.gradle.kts invokes jpackage/jlink from the pinned JDK, with:
  modules: java.se,jdk.httpserver,jdk.crypto.ec,jdk.unsupported,jdk.charsets,
           jdk.zipfs,jdk.net
  jlink: --strip-debug --no-man-pages --no-header-files
It retains native executables and runtime/legal. For the full application build,
use the matching StreamBridge commit recorded in release-manifest.json and its
Gradle wrapper/settings, following docs/alpha-release.md. Source licensing remains
GPLv2 with Classpath Exception and the original component-specific notices.
